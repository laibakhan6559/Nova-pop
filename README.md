# Nova Pop - Bubble Shooter

20 levels, 4 worlds, 7 special bubbles. Vite + canvas, with canvas-confetti and @fontsource/fredoka.

## Run locally
    npm install
    npm run dev

## Deploy on Vercel
1. Push this folder to GitHub (or run `npx vercel` inside it).
2. Import in Vercel - framework "Vite" is auto-detected (build: `npm run build`, output: `dist`).

## Special bubbles
Frozen, Stone, Golden star (free power-up), Shifter (changes colour each shot),
Bomb, Rainbow, Zap (row clear). Extras: hint button, ceiling-drop meter, colour-blind shapes mode, star ratings, saved progress.
